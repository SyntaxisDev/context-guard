Handoffs live in `{{handoff_dir}}`, shared by every runtime. Keep an existing saved handoff path. A nonexistent path given by a context-guard hook is provisional: on first save, choose a concise 3–6-word task name from context, sanitized to a lowercase hyphenated slug of at most 40 characters, and keep the directory and the exact identity suffix. Never copy or truncate the opening prompt; use `task` if unclear. Without a hook path, use that directory with the semantic slug and a collision-resistant suffix. Do not encode the runtime in the filename; record the source runtime and chat ID inside the file. When the task is finished, set `Status: done` so it drops off the list.

When continuing work, check `{{handoff_dir}}/pending/` for runner reports for the exact workspace, even when no handoff exists yet. Merge the request, result, verified completion and remaining work into the matching handoff, creating one if needed; process success does not prove task completion. Save the handoff first, then delete only the exact report files consumed. If saving fails, delete nothing.
